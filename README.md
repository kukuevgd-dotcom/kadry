# Kadry

Кадровый учёт: сотрудники и отпуска.

Курсовой проект по дисциплине «Разработка программных модулей»: десктопное приложение для отдела кадров небольшой организации. Приём и увольнение сотрудников, заявления на отпуск с согласованием руководителем, приказы, автоматический расчёт остатков отпускных дней (по ТК РФ основной отпуск — 28 календарных дней), график отпусков на год и отчёты.

## Стек

- C# / .NET 10, WPF
- MVVM — своя реализация (RelayCommand, ViewModelBase), без сторонних библиотек
- SQLite + Entity Framework Core (Code First, миграции)
- тесты на xUnit
